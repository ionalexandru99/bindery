### Fixed
- **A download holding several books imports the one it was grabbed for** (#3224): when several ebook files of one format would land in the same place, the one whose file name or EPUB title is closest to the book is placed, rather than whichever came first on disk. The external drop folder does the same.
- **More multi-book pack names are recognised** (#3224): `Foundation series by Isaac Asimov`, `Series 1-7`, a bracketed count such as `(11 Books)`, `Books Collection`, `Series Pack` and `Saga eBooks` are no longer auto-grabbed for a single book. Names such as `Series by Pierce Brown, Book 1` and `A Series of Unfortunate Events` still are.
- **Release notes are not imported as a book format** (#3224): an ebook file under 4 KiB in a download, like the 253 byte `.txt` some releases ship beside the book, is skipped instead of being tracked and pushed to Calibre. Manual import still places a file that small.
